Linux musl 构建材料

原始材料来自 Alpine Linux 3.22 的 x86_64 开发包和运行库。
头文件保持原始内容及版权声明，不分发 Alpine 动态库实现。
符号清单位于 sdk/defs/linux/musl/，与 GNU 清单独立维护。
ALSA 的 Alpine 构建关闭符号版本，因此不添加 GNU 的版本后缀。
FILES.txt 记录开发包内的头文件来源和提取位置。

头文件提取：在 SDK 仓库根目录执行 python linux/extract.py musl。
packages.json 固定开发包地址和 SHA256；headers.json 固定头文件路径和 SHA256。
脚本不依赖 Sokol，不生成 .def；链接符号及其生成工具在 ZhuYu 仓库维护。
